# Mathoscope Knowledge Graph

Mathematics knowledge graph for Mathoscope built from Mathgloss and Wikidata.

## Access

A demo of the knowledge graph is available online. You can access the demo
using the following credentials:

- *Connection URL:* neo4j+s://cb98a085.databases.neo4j.io
- *Username:* readonly
- *Password:* mathoscope

[This website](browser.neo4j.io) can be used as a web interface to view the
graph.

The demo is read-only, so you won't be able to add nodes or modify the database
in any way. 

For information about the Cypher language used to query the database, see 
[the Manual](neo4j.com/docs/cypher-manual/current/introduction).
